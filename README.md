# 路線王

鉄道オープンデータの[鉄道駅LOD](https://uedayou.net/jrslod/)を使った
鉄道路線を当てるクイズゲームです。

路線内の駅名を元に時間内に路線名を検索して選択してください。

### アプリ

<https://rosenoh.uedayou.net/>

Vue 3 + Vuetify 4 + Vite 製の SPA です。

## Project setup
```
npm install
```

### Compiles and hot-reloads for development

npm run dev

```
npm run build
```

```

```
